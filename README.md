# TropicalGradDescent

This repository provides software and data to implement the numerical experiments in [Talbut et al.](https://arxiv.org/abs/2405.19551). These experiments focus on implementing tropical gradient methods to solve tropical optimisation problems in statistics.

Tropical gradient descent takes advantage of the polyhedral and combinatorial structures arising in tropical geometry to propose a versatile method for approximating local minima in tropical statistical optimization problems - a rapidly growing body of work in recent years. Numerical experiments demonstrate the method's superior performance compared to classical gradient descent for tropical optimization problems which exhibit tropical convexity but not classical convexity. We also demonstrate the seamless integration of tropical descent into advanced optimization methods, such as Adam, offering improved overall accuracy.

For more detail on the underlying theory of tropical gradient descent for statistical location problems, please see [Talbut et al.](https://arxiv.org/abs/2405.19551).

## Tropical Location Problems
We perform numerical experiments using tropical gradient methods and their classical counterparts to solve 7 different tropical optimisation problems:

* `FW` [Fermat--Weber points](https://epubs.siam.org/doi/10.1137/16M1071122)
* `FM` [Fr\'echet means](https://arxiv.org/pdf/2502.05322)
* `WD2` [2-Wasserstein distances](https://www.aimsciences.org/article/doi/10.3934/fods.2026001?viewType=HTML)
* `WDinf` [inf-Wasserstein distances](https://www.aimsciences.org/article/doi/10.3934/fods.2026001?viewType=HTML)
* `LR` [Linear Regression](https://epubs.siam.org/doi/10.1137/21M1428297)
* `LogR` [Logistic Regression](https://pmc.ncbi.nlm.nih.gov/articles/PMC11219468/)
* `PCA` [Principal Component Analysis](https://academic.oup.com/bioinformatics/article/36/17/4590/5855129?login=false)

These problems are solved for the simulated datasets in `Data`.

## Description of Python Scripts

The repository contains the following set of Python scripts:

* `trop_fns.py` provides supplemental tropical geometry functions used in distance computation.
* `experiments.py` contains the functions to run each gradient method for a specified problem type.
* `[Prob]_lr_training.py` computes the optimal learning rate for each gradient method for `[Prob]`.
* `[Prob]_experiment.py` performs each gradient method with optimal learning rate for `[Prob]`.
* `analysis.py` contains the functions to analyze and visualize the output of each numerical experiment.

The Jupyter notebook `TGD_notebook.ipynb` presents a step-by-step exploration of the results shown in [Talbut et al.](https://arxiv.org/abs/2405.19551).

## Output and Results

The `DataFrames` directory contains computed results generated by the analysis scripts. The `Figures` directory contains visualizations and plots of log error achieved by each gradient method for different problems.
